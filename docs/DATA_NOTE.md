# Data Provenance

**This project ships with no real patient data.** Everything you see on first
run — the 12 demo patients, the trained risk models — is generated by
`backend/app/synthetic_data.py`.

## Why synthetic data, not real ADNI/OASIS

Both cohorts require a signed Data Use Agreement and manual, credentialed
registration:

- **ADNI** — adni.loni.usc.edu — requires an approved application through
  LONI before any subject-level MRI/PET/biomarker/cognitive data can be
  downloaded.
- **OASIS** — oasis-brains.org — free to register, but still requires a
  human to accept the data use terms; not scriptable end-to-end.

Neither can be fetched automatically, and hackathon judges/RINPAS should be
told plainly: **the models here are trained on a synthetic cohort whose
per-feature ranges and correlations are set to approximate published ADNI/OASIS
population statistics** (MoCA/MMSE/CDR conventions, plasma biomarker panels
such as Aβ42/40, p-tau181, NfL, GFAP; FreeSurfer-style MRI volumetrics;
amyloid/tau/FDG PET SUVR conventions) — not derived from any real subject
record. See `GET /api/meta/model-card` for the same disclosure surfaced live
in the API, and the "Model Card" panel on the dashboard.

## Swapping in real data

The rest of the pipeline (`app/ml/features.py`, `app/ml/train.py`,
`app/ml/pipeline.py`) is written against fixed column names, not against the
generator. Once your team has ADNI/OASIS access:

1. Write a loader that produces a `pandas.DataFrame` with the same columns as
   `synthetic_data.generate_cohort()` (see `STAGE_FEATURES` in
   `features.py` for the exact per-stage column lists) plus a `diagnosis`
   column in `{CN, MCI, AD}`.
2. Point `app/ml/train.py`'s `train_all()` at that loader instead of
   `generate_cohort()`.
3. Retrain (`python -m app.ml.train`) and re-seed.

No changes are needed anywhere else — the FastAPI routes, the adaptive
gating logic, and the React dashboard all consume the trained model
artifacts, not the data source.

## Honesty checklist before any real clinical demo

- [ ] Say "synthetic demo cohort" out loud when presenting, every time.
- [ ] Don't claim validated accuracy — the metrics on the Model Card are
      against a synthetic held-out set, not a clinical validation study.
- [ ] This is a triage-prioritization prototype, not a diagnostic device.
